# 样例（examples）

这里放的是**真实产物**，不是我编的示例数据：

| 文件 | 是什么 |
|---|---|
| `transcript-sample.md` | `bili-learn transcript` 的真实输出（截取前 40 行）。注意文件头：**字幕覆盖率**、行数、来源链接 |
| `note-sample.md` | 由上面那段转写"消化"出来的真实笔记，含**已核实**与**存疑**段落 |

## 看两个细节

**1. 转写文件头带覆盖率**

```markdown
# 建议所有人：关注你的Agent上下文占用率【提效必备！】
- bvid: BV1ZK7N6sEiU
- 时长: 892s  |  字幕: 中文  |  行数: 442
- 字幕覆盖: 100%          ← 低于 80% 会在这里标 ⚠️
- 来源: https://www.bilibili.com/video/BV1ZK7N6sEiU/
```

**2. 笔记里的时间戳可以双通道回查**

```markdown
## 核心内容
- [00:08:05] 占用率 >50% 性能开始退化；到 80%~90% 严重退化 …
- ✅ 已核实（读本机实现）：阈值 = floor(min(W × 0.8, W − O − 65536)) …
```

- `[00:08:05]` → 回到**转写**里那一句（听觉通道）
- 如果这条视频抓了帧，同一时间戳还能对到 `data/frames/<bvid>/000805.jpg` 那张**板书**（视觉通道）
  ——选帧、算钱、给路径都由 `bili-learn frames --pick` 完成

## 为什么笔记里保留"存疑"

`note-sample.md` 的最后一节不是凑数：**把"视频说的"和"我验证过的"分开**，
是这类工具最容易被忽略、但最影响长期价值的地方——三个月后你会需要知道
"这句话当初是不是只是 UP 主的个人判断"。
